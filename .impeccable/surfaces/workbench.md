## Optional print and game preparation

For a completed model, “Preparar una versión” adds the “Impresión”/“Juegos” destination choice using the incumbent segmented radio style. Printing offers balanced (500,000 faces), detailed (1,000,000) or full geometry, plus a details disclosure containing the optional largest-piece choice; separate pieces are retained by default. Games offers the face limit (initially 50,000) and texture sizes from512 to4096px (initially2048). Each action creates a child version and retains its source. Preparation runs in the native CPU worker; GPU generation/refinement keeps its existing Hub coordination.

The versions list scrolls within a320px maximum height. Repaired and game versions use the existing selected-row treatment and actual queue/cancel/error states. A completed game row displays its measured result face count, not the user's requested limit. The existing comparison can inspect a child alongside the original. The preparation action selects STL for repair or GLB for games in the export controls, while all format and scale choices remain available.

Completed processing reveals a written report summary and “Descargar informe de la pasada”. Printing reports measured closure, component count and open boundary edges; game output reports result faces, GLB size and texture size. Unverified closure or a missed requested face limit is stated in words and also uses the incumbent coral issue color. These measurements do not guarantee a printable model, wall thickness, supports, animation retopology or rigging.
